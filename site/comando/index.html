Comando !mira para tu chat

Tus espectadores escriben !mira donk y el bot responde con el código de su mira y un enlace. Gratis y sin registrarte: funciona con Nightbot, StreamElements y cualquier bot que pueda leer una URL.

1Pruébalo

!mira
tu_espectador !mira donk
Nightbot …

Vale el nombre (también incompleto o con @), el usuario de FACEIT, el SteamID64 o un enlace de Steam.

2Elige las opciones

Útil para que !mira a secas enseñe tu propia mira. Tiene que estar en la web: si no estás, envía una demo de una partida tuya.
